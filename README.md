# Prediction Real Estate Prices in Bangkok

การทำนายราคาอสังหาริมทรัพย์ในแต่ละพื้นที่ของกรุงเทพ ฯ มีความสำคัญอย่างยิ่งในหลายมิติ   
• ประการแรก ช่วยให้ผู้ซื้อและนักลงทุนสามารถวางแผนการเงินและตัดสินใจเลือกทำเลที่เหมาะสมกับงบประมาณและความต้องการ   
• ประการที่สอง ผู้พัฒนาโครงการสามารถใช้ข้อมูลการทำนายราคาเพื่อกำหนดแผนการลงทุนและพัฒนาโครงการที่ตอบโจทย์ตลาดได้ดีขึ้น   
• ประการที่สาม หน่วยงานภาครัฐหรือองค์กรด้านผังเมืองสามารถนำข้อมูลเหล่านี้ไปใช้ในการวางแผนพัฒนาเมืองอย่างมีประสิทธิภาพ นอกจากนี้ยังช่วยลดความเสี่ยงและสร้างความโปร่งใสในตลาดอสังหาริมทรัพย์  
 

## 1. Project Objective
• เพื่อศึกษาปัจจัยที่มีผลต่อราคาอสังหาริมทรัพย์ในแต่ละพื้นที่ของกรุงเทพ ฯ    
• เพื่อพัฒนาแบบจำลองสำหรับทำนายราคาอสังหาริมทรัพย์ในแต่ละทำเลอย่างแม่นยำ  
• เพื่อสร้างเครื่องมือสนับสนุนการตัดสินใจสำหรับผู้ซื้อนักลงทุนและผู้พัฒนาอสังหาริมทรัพย์
